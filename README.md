# Sleeptimer

A small Windows desktop app that shuts down your PC after a set amount of time. Set the hours, minutes and seconds, click **Sleep**, and the PC shuts down when the countdown ends.

## Features

- Countdown of up to 24 hours, 59 minutes and 59 seconds.
- The countdown follows the system clock, so it stays accurate even if the app is busy or the PC goes to sleep mid-countdown.
- A 30-second Windows shutdown warning when the countdown ends, so you can still save your work or cancel.
- **Abort Sleep** cancels the countdown (or the 30-second warning) and restores the time you entered.
- Warns you if you try to close the app while a countdown is running.

## Requirements

- Windows
- .NET Framework 4.7.2 or later

## Usage

1. Run `Sleeptimer_C#.exe`.
2. Use the arrows to set **Hours**, **Minutes** and **Seconds**. Going past 59 minutes or 59 seconds rolls over into the next unit.
3. Click **Sleep** to start the countdown. The fields count down as time passes.
4. When the countdown reaches zero, Windows shows a notice and shuts down 30 seconds later.

To cancel, click **Abort Sleep** at any time during the countdown or the 30-second warning. You can also cancel the warning from a command prompt with:

```
shutdown /a
```

> **Note:** The countdown runs inside the app. If you close the app before the countdown ends, the PC will **not** shut down.

> **Warning:** When the 30-second warning ends, Windows closes all open apps, including ones with unsaved work.

## Building from source

1. Clone the repository:
   ```
   git clone https://github.com/TeDDzTeR99/Sleeptimer_Csharp.git
   ```
2. Open `Sleeptimer_C#.slnx` in Visual Studio or JetBrains Rider.
3. Build and run the `Sleeptimer_C#` project.

The form layout can be edited visually: open `Sleeptimer_C#/Main.cs` and switch to the **Designer** tab.

### Signing key

The project signs its ClickOnce manifests with `Sleeptimer_C#_TemporaryKey.pfx`, which is not stored in the repository. If the build fails because the key is missing, create a new one under **Project Properties → Signing**, or turn off **Sign the ClickOnce manifests**.
